## 4. 单条脚本结构（完整分镜表）

一条脚本 = 一个 `.md`，含五块：

1. **元信息**：编号 / 人群 / 主打功能 / 漏斗阶段 / 目标时长 / 标题 + 封面文案 / 平台话题标签。
2. **口播全文**：可直接配音的逐字稿。
3. **分镜表**：表格列 `镜号 | 时间 | 画面内容 | 口播 | 屏幕字幕 | 转场 | 素材类型`。素材类型取值：截图 / 配图 / 录屏 / 数字人口播 / 实拍。
4. **素材清单（对应核心）**：
   - ① 截图清单：抓哪个页面 + 什么状态，每项给确定目标文件名（`screenshots/NN-MM-Sx-<描述>.png`）。
   - ② 配图 prompt：中文 AI 绘图提示词，每项给确定目标文件名（`images/NN-MM-Ix-<描述>.png`）。
   - ③ 录屏镜头说明：操作路径 + 时长，给确定目标文件名（`video/NN-MM-Vx-<描述>.mp4`）。
   - ④ BGM / 音效建议。
5. **制作备注**：拍摄注意、合规口径、平台差异。

模板落在 `_TEMPLATE.md`，所有脚本严格套用同一字段顺序。

## 5. 脚本 ↔ 文件「对应」落地机制

目录即对应关系。每条脚本配一个同名 `.assets/` 文件夹，预建空占位、命名锁定：

```
marketing/video-scripts/
  README.md                       # 总索引 + 分布矩阵 + 制作规范 + 文件名约定
  _TEMPLATE.md                    # 脚本模板
  _facts.md                       # 全脚本共用产品事实(防编造)
  01-律师法务/
    01-01-<slug>.md               # 脚本(内含素材清单, 每项指向下方确定文件名)
    01-01-<slug>.assets/
      screenshots/  images/  video/
    01-02-<slug>.md
    01-02-<slug>.assets/ ...
  02-医院科室/ ... 10-企业培训零基础/
```

- 编号 `NN-MM`（人群-序号）唯一，脚本文件与 `.assets` 文件夹同名前缀，天然一一对应。
- 脚本素材清单中每一项都写死目标文件名，与 `.assets/screenshots|images|video/` 下应放的文件名完全一致。
- 二进制媒体由团队或项目自带 AI 能力按文件名填入，填好即与脚本对齐。
