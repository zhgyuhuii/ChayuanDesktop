### Task 2.2: ConversationView 接 onFeedback → 重持久化 + 更新状态

- [ ] **ConversationView.tsx**:渲染 MessageBubble 处(先 Read 找到 `<MessageBubble ... />`)传 `onFeedback={handleFeedback}`。新增 handler(用现成 `localUserId`/`activeId`/`appendMessage`/`setChatMessages`):
```tsx
const handleFeedback = React.useCallback(
  (messageId: string, value: 1 | -1) => {
    // 更新内存消息
    setChatMessages((prev) => prev.map((m) => (m.id === messageId ? { ...m, feedback: value } : m)));
    // 重持久化(appendMessage 是 INSERT OR REPLACE)
    if (activeId) {
      const msg = chat.messages.find((m) => m.id === messageId);
      if (msg) void appendMessage(activeId, { ...msg, feedback: value }, localUserId);
    }
  },
  [activeId, localUserId, setChatMessages, chat.messages],
);
```
