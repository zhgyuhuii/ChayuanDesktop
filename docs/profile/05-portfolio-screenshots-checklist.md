## 怎么截 / 处理(中文要点)
1. **分辨率**:截 1280–1920 宽,清晰;Upwork 封面建议 ~16:9。
2. **干净**:截图前把界面调到展示状态(有内容、无报错、无调试面板);浏览器截图去掉书签栏。
3. **脱敏(重要)**:
   - 真实用户名、手机号、邮箱、公司名、政府/部委字样 → **一律打码或换成示例数据**。
   - 商业产品名(察元)可留;政府/国防/高校项目**不放可识别截图**,用架构图代替。
4. **加标注**:在关键处加箭头/文字标注(如"citations""generated SQL""local models"),客户秒懂。
5. **统一风格**:同一作品集所有图用一致的边框/底色/字体,显专业(可用 Figma/Canva 套个统一框)。
6. **每张配一句 caption**:Upwork 每张图能写说明,用"这是什么 + 解决什么"。
7. **demo 视频**:若能录 30–60 秒操作视频(察元对话→RAG→出图),比静图更强,放 Card 1。

## 没有现成截图怎么办
- 本地把察元跑起来(桌面版/Web)逐个功能截。
- 老项目(O2O/农业/考试)没截图 → **画架构图**替代,一样有说服力(画 1 张干净的微服务/系统拓扑即可)。
- 官网 aidooo.com 的现成产品图也可直接用作佐证。
