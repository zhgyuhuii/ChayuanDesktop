# Upwork 求职信 / Proposal 模板(投标临门一脚)

> Proposal 是接单的决定性一步——客户先看你 proposal 的**前 2 行**(列表里只露出开头)。
> 铁律:**别自我介绍开头**(客户不关心你);**第一句直接说他的问题/目标**;短(80–150 词);具体;结尾问一个问题引导回复。
> 英文模板可直接改用;`[方括号]` 处按招聘帖替换。中文是说明。

---

## 0. 万能结构(5 句法)
1. **钩子**:复述他的目标 / 痛点(证明你读了帖子)。
2. **我能做**:针对性地说怎么解决 + 你做过同类。
3. **证据**:一句话甩硬成果(察元 / 链接)。
4. **下一步**:提议一个小而具体的起步(降低他的决策成本)。
5. **提问**:问一个具体问题(触发回复 = 提高进线率)。

⚠️ 不要写 "Dear Sir/Madam"、"I am a developer with 19 years..." 这种开头;不要长篇罗列技能。

---

## 1. RAG / 文档问答类岗位
> Hi [Name] — you want an AI assistant that answers from your own [documents/PDFs/knowledge base] **accurately, with sources** rather than hallucinations. That's exactly what I build.
>
> I recently architected a production AI platform where RAG answers cite the exact source passage, with multi-query retrieval + reranking and hybrid (keyword+vector) search — so every answer is traceable. I can do the same over your data (Python/FastAPI + a vector DB + your choice of OpenAI or a self-hosted model).
>
> Live example of my work: https://aidooo.com (open-source: github.com/zhgyuhuii/chayuan-desktop-releases).
>
> To start, I'd suggest a small paid milestone: ingest a sample of your docs and show grounded Q&A with citations, so you can verify quality before committing.
>
> Quick question: roughly how many documents, and which formats (PDF/Word/Excel/web)? And do you prefer a cloud LLM (OpenAI) or fully self-hosted for privacy?

## 2. 全栈 Web App 类岗位
> Hi [Name] — you're looking to build [their app: e.g., a dashboard / SaaS / internal tool] end-to-end. I deliver the whole thing solo: architecture, backend, frontend, and deployment — so you don't have to coordinate multiple freelancers.
>
> 19 years of full-stack experience (React/Vue + Python(FastAPI)/Java(Spring Cloud)); I've shipped everything from cloud-native microservice platforms to a smart-agriculture app I built single-handedly. Recent work: https://aidooo.com.
>
> For your project I'd start by confirming the core flows and data model, then deliver a working vertical slice (one full feature, deployed) within the first milestone so you see real progress fast.
>
> One question: do you already have designs/wireframes and a preferred stack, or would you like me to propose the architecture?

## 3. Text2SQL / 数据问答类岗位
> Hi [Name] — you want [your users / your team] to query [the database] in plain English instead of writing SQL. I've built exactly this.
>
> My Text2SQL engine does schema linking → SQL planning → **read-only validation** (it can never modify data) → execution, and returns the answer *plus* the generated SQL and the result table for full transparency. It works across many SQL dialects.
>
> Example of my work: https://aidooo.com.
>
> I'd suggest starting with a milestone against a read-only copy of your schema, proving accurate, safe queries on your top 10 real questions.
>
> Question: which database (Postgres/MySQL/SQL Server/…) and about how many tables are in scope?

## 4. 通用 AI / LLM 集成类岗位
> Hi [Name] — you want to add [AI feature: chatbot / automation / agent] to [their product]. I build production LLM features that actually ship, not just demos.
>
> I architected a full AI platform (RAG, Text2SQL, multimodal, and a gateway that runs both cloud models and self-hosted ones) — so I can plug AI into your product the way that fits your data-privacy and budget constraints. Stack: Python/FastAPI + your frontend. Example: https://aidooo.com.

>
> Quick question: what does success look like for the first version, and do you have a data-privacy requirement (cloud vs self-hosted)?

## 5. 桌面 / 跨平台应用类岗位
> Hi [Name] — you need a desktop app for [Windows/Mac/Linux] that [does X]. I build cross-platform desktop apps in Electron and Tauri, including deep OS integration (process/file/system access) when needed.
>
> I've shipped a Linux desktop-management platform (Electron + Vue + native C/C++) and package multi-OS builds. Example: https://aidooo.com (releases: github.com/zhgyuhuii/chayuan-desktop-releases).
>
> I'd suggest a first milestone delivering the core window + main feature, packaged and installable on your target OS.
>
> Question: which OSes must you support, and is there any native/system-level functionality involved?

## 6. 沟通方式的诚实加分句(按需加在结尾)
> I work async and communicate clearly in writing — I keep you updated with short daily notes and a shared task board, so you always know status without needing calls. (If you prefer, I'm happy to do brief written check-ins.)

**中文说明**:你只能书面英语——把上面这句加进 proposal,**主动把"文字异步沟通"包装成优点**(很多客户反而喜欢不打扰、有记录)。**别等客户问起口语**;若对方坚持要视频面试,礼貌说明你以书面/录屏沟通为主、可文字回答技术问题。

---

## 7. 提交 proposal 的实操要点(中文)
- **前 2 行最重要**:列表预览只露开头,务必第一句戳中他的需求,别浪费在自我介绍。
- **每条都改**:复制模板后,把 `[ ]` 换成帖子里的具体词(他用什么词你用什么词)。
- **短**:80–150 词,客户一眼读完。
- **附链接**:aidooo.com + GitHub releases,给"这人是真做过"的即时信任。
- **报价**:冷启动期可用 $35/hr 或按这个里程碑给个固定小额(如首里程碑 $150–500),让他低风险试用。
- **Connects**:优先投**匹配度高、客户有充值认证、招聘描述清楚**的帖子,别海投。
- **回复速度**:越快越好(尤其帖子刚发 1 小时内)。
