## 3. 月度 Retainer(稳定现金流,站稳后推)
> **Ongoing AI/Full-Stack Support** — a set number of hours/month for maintenance, iteration, and new features. Priority response, async updates.
> - **Part-time:** ~40 hrs/mo — $[1,600–2,800]/mo
> - **Dedicated:** ~80–160 hrs/mo — quote on scope

**中文**:retainer 是自由职业最香的——一个长期客户顶十个零散单。结单满意的客户主动问"能不能长期合作"时推这个。

## 4. 报价里要写清的边界(防扯皮)
- **Included**:架构、编码、部署、合理范围内的修改、交付文档。
- **Not included**:无限改需求、第三方付费服务费(API/服务器/域名)、超出约定的新功能(走新里程碑)。
- **Payment**:里程碑付款 + 平台托管(escrow);每个里程碑满意后释放。
- **Revisions**:每里程碑含 [1–2] 轮修改;超出按小时或新里程碑。
- **IP**:验收付款后代码/产权归客户;可签 NDA。

---

## 5. 报价心法(中文)
1. **先问预算和成功标准**,再报价——别盲报。
2. **给区间或分档**(Basic/Pro),让客户有得选、容易下单。
3. **AI 单别按小时**:一个 RAG 项目固定 $2k,比 $35×小时 体面也更赚。
4. **首单可让利**(下限价/小里程碑)换评价,但**别免费**;免费会被当廉价。
5. **涨价靠评价**:每攒几个好评就上调,老客户可维持旧价。
