## 中文备注 · 填表与心理优化

- **冲 All-Star 档案完成度**:Guru 把档案完整度做成可见徽章,直接影响排序。把 Overview / Skills / Services / Portfolio / Work History / Education 全部填满,拿到 All-Star。
- **Services 清单是 Guru 的灵魂**:客户常按服务类目找人,把上面 5 条服务都建出来、各配一句具体能力,比一段笼统简介更易被搜到。
- **强调 SafePay**:沟通里主动提「happy to work through Guru SafePay」,中小企业客户吃这套(资金担保 = 信任)。
- **口语**:文字 + 站内信为主,基本不需通话;有要求转录屏/文档。
- **报价**:可在不同 Service 下挂固定价套餐(类似 Fiverr 三档),比纯时薪转化更好。
