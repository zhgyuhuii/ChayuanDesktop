## 中文备注 · 用法与心理优化

- **Remote OK ≠ 接单平台**:这是招聘板。主要价值是 ①被动挂简历被雇主搜到 ②主动投上面的远程岗。别指望像 Fiverr 那样有人来下单。
- **Headline 要塞关键词 + 远程信号**:雇主按 `python` `rag` `react` 这类 tag 搜人,Tags 填准最重要;主动写 `Remote GMT+8` 表明远程就绪。
- **附简历 PDF**:直接用上级目录 `Yuhui-Zhang-Resume-EN.pdf`,这是招聘板的硬通货。
- **求职信要短**:雇主每天看几十封,3 段封顶,前两行说清「19 年 + AI 旗舰作品 + 远程就绪」。
- **口语**:看岗位;全职远程岗多半会有视频面试,合同/异步岗较宽松。主动给「recorded walkthrough」降低实时通话压力。
- **优先级**:★(被动渠道)—— 挂上去成本低,顺手做;成单靠主动投岗。
