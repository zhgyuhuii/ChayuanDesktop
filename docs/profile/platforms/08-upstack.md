## 中文备注 · 现实评估与建议

- ⚠ **口语门槛**:UpStack 面向北美客户、长期远程合作,入会和客户匹配普遍要英文实时沟通(沟通评估 + 技术面 + 实时编码)。**口语没到能从容实时交流前,通过率有限,列为第二批。**

- **时薪 $50–80**:精选网起点别用 $35。
- **优先级**:口语提升前先做第一批文字异步平台;UpStack/Toptal/Scalable Path 一起作为口语达标后的目标池。
