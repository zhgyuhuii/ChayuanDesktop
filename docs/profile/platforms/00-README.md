## 三、所有平台通用的三条心理优化(已贯穿每个文件)

1. **前两行定生死**:Fiverr/Freelancer/PPH 的搜索结果只露出标题 + 头一两句,所有文案都把「19 年 + 一个人端到端交付 AI/全栈产品 + 旗舰作品察元」压在最前面。
2. **把口语弱包装成优势**:统一表述 "professional written English, async/text-first" —— 对客户读作「不打扰、留记录、跨时区可靠」,而不是「英语不好」。
3. **用具体数字建立资历感**:`19 years` / `20+ platforms` / `170+ models` / `5 repos, 3700+ commits` / `4 product editions` —— 比形容词更能锚定「资深、真做过」。
