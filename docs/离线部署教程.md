# 察元 AI — Docker 离线部署全流程教程

> 适用：内网/无公网服务器，Linux **x86_64 与 aarch64 均原生支持**（离线包已双架构）。
> 流程分两段：**联网机**（打包镜像/下载安装包）→ **离线机**（安装运行）。

> 🚀 **已做成一键包**：仓库 `offline-install/` 目录已含 x64+arm64 的 Docker/Compose 离线安装包、
> 察元全部镜像导出包、部署文件和 `install.sh`。离线机上一条命令完成全部安装启动：
> `sudo ./install.sh`。目录结构与生成方法见 `offline-install/README.md`。
> 下文是手动全流程（理解原理/排错用）。

---

## 一、联网机：准备离线包

### 1. 下载 Docker 离线安装包

| 组件 | 下载地址 | 文件 |
|---|---|---|
| Docker 静态二进制 | `https://download.docker.com/linux/static/stable/x86_64/`（国内镜像 `https://mirrors.aliyun.com/docker-ce/linux/static/stable/x86_64/`） | 如 `docker-27.5.1.tgz` |
| Compose 插件 | `https://github.com/docker/compose/releases` | `docker-compose-linux-x86_64`（v2.x） |

### 2. 构建察元镜像 + 拉取基础设施镜像

```bash
cd 项目根目录
./docker/build.sh                       # 构建察元集成镜像 → chayuan:latest（tag=VERSION，当前 2.0.357）

docker pull postgres:15
docker pull redis:latest
docker pull minio/minio:RELEASE.2023-03-20T20-16-18Z
docker pull quay.io/coreos/etcd:v3.5.5
docker pull milvusdb/milvus:v2.6.15
```

### 3. 导出镜像 + 打包项目文件

```bash
# 所有镜像导出一个 tar
docker save -o chayuan-offline-images.tar \
  chayuan:latest postgres:15 redis:latest \
  minio/minio:RELEASE.2023-03-20T20-16-18Z \
  quay.io/coreos/etcd:v3.5.5 \
  milvusdb/milvus:v2.6.15

# 打包部署所需文件（compose 会挂载 ../chayuan-server/vendor/bundled_models，目录结构必须保留）
tar -czf chayuan-deploy-files.tar.gz docker/ chayuan-server/vendor/bundled_models/
```

**离线包清单**（拷到 U 盘/内网传输）：

```text
docker-27.5.1.tgz                  # Docker 引擎
docker-compose-linux-x86_64        # Compose 插件
chayuan-offline-images.tar         # 全部镜像（约 8~12 GB）
chayuan-deploy-files.tar.gz        # compose 文件 + nginx.conf + 模型目录
```

> 模型（GGUF）也离线：把 chat / embedding / rerank / asr 的 GGUF 提前放进
> `chayuan-server/vendor/bundled_models/`（结构见 `docker/README.md`），一起打包带走。
> 不放模型则聊天报「未就绪」；云端 API 需有网时在前端网页里配置。

## 二、离线机：安装 Docker + Compose

```bash
# 1) 安装 Docker
tar -xzf docker-27.5.1.tgz
sudo cp docker/* /usr/local/bin/

# 2) 注册 systemd 服务（新建 /etc/systemd/system/docker.service）
sudo tee /etc/systemd/system/docker.service <<'EOF'
[Unit]
Description=Docker
After=network.target
[Service]
ExecStart=/usr/local/bin/dockerd
Restart=always
[Install]
WantedBy=multi-user.target
EOF
sudo systemctl daemon-reload
sudo systemctl enable --now docker
docker version                      # 验证：client/server 都有输出

# 3) 安装 Compose 插件
sudo mkdir -p /usr/local/lib/docker/cli-plugins
sudo cp docker-compose-linux-x86_64 /usr/local/lib/docker/cli-plugins/docker-compose
sudo chmod +x /usr/local/lib/docker/cli-plugins/docker-compose
docker compose version              # 验证
```

> 若系统已有 docker-ce 且能离线装 rpm/deb，直接用 `download.docker.com/linux/centos/7/x86_64/stable/Packages/` 下的 `docker-ce-*.rpm` + `docker-compose-plugin-*.rpm`，`sudo rpm -ivh *.rpm` / `dpkg -i *.deb` 安装即可，跳过上面手动建服务。

## 三、导入镜像并启动

```bash
# 1) 导入镜像（耐心等几分钟）
docker load -i chayuan-offline-images.tar
docker images                       # 应看到 6 个镜像

# 2) 解开部署文件（保持 docker/ 与 chayuan-server/ 的相对结构）
tar -xzf chayuan-deploy-files.tar.gz      # 假设解到 /opt/chayuan/

# 3) 启动
cd /opt/chayuan/docker
docker compose up -d
```

启动顺序自动编排：postgres/redis/minio/etcd → milvus → chayuan-server（自动 init 建表）。
**首次启动约 2~3 分钟**（milvus 初始化 + 察元 sidecar 预热），查状态：

```bash
docker compose ps                          # 全部 Up/healthy 即成功
docker compose logs -f chayuan-server      # 看启动日志
curl http://127.0.0.1:8080/healthz         # 健康检查
```

防火墙放行端口：`8080`（网页主入口）/ `62581`（后端 API，WPS 等固定连它，**不可改**）。
公网部署只暴露 8080，另一个限内网。（新版已移除 NiceGUI 面板，无 `:8502` 端口）

## 四、初始化与配置使用

1. **设管理员**：浏览器打开 `http://<服务器IP>:8080`，首次访问弹「设置管理员」向导，设用户名密码即进入（一次性，匿名模式下其他访问仍免登录）。
2. **模型就绪**：本地 GGUF 已随目录挂载，启动自动注册；`docker compose restart chayuan-server` 可刷新。
3. **云端模型（可选）**：在前端网页的模型配置里填 OpenAI/通义/智谱等 API Key（需该机能达公网，纯离线跳过）。
4. **多用户/登录模式（可选）**：`cp .env.network.example .env`，编辑：
   ```bash
   CHAYUAN_AUTH_REQUIRED=true
   CHAYUAN_ALLOW_REGISTRATION=false
   JWT_SECRET=<openssl rand -hex 64 生成>     # 有网机器上生成好拷过来
   AUTH_DEFAULT_ADMIN_USERNAME=admin
   AUTH_DEFAULT_ADMIN_PASSWORD=你的密码       # 预置后首访不弹向导
   ```
   然后 `docker compose up -d` 重建生效。

## 五、日常运维

```bash
cd /opt/chayuan/docker
docker compose ps                        # 状态
docker compose logs -f chayuan-server    # 日志
docker compose restart chayuan-server    # 改模型/配置后重启
docker compose down                      # 停止（数据保留）
docker compose up -d                     # 启动
docker compose exec chayuan-server bash  # 进容器排查
```

**升级**（离线流程）：联网机 `./docker/build.sh` 出新镜像 → `docker save chayuan:latest | gzip > chayuan-new.tar.gz` 带过来 → `docker load -i chayuan-new.tar.gz` → `docker compose up -d`（平滑换容器，数据不丢）。

**备份**：定时备份 `docker/volumes/`（postgres/redis/minio/milvus 数据）、`docker/data/`（知识库/上传文件）、`chayuan-server/vendor/bundled_models/`（模型）。升级/删容器都不影响这些目录。

**常见问题**：

| 现象 | 处理 |
|---|---|
| `8080 already allocated` | 端口被占/有旧容器残留，`docker rm -f` 同名容器；或 `.env` 里改 `CHAYUAN_WEB_PORT` |
| 聊天报「未就绪 no local candidate」 | 没放本地模型或没配云端 API；放 GGUF 后 `docker compose restart chayuan-server` |
| 启动后几分钟无响应 | 正常预热（sidecar 加载模型），等 `start_period`（180s）过后再看 |
| chayuan 反复重启 | `docker compose logs chayuan-server`，多为 volumes 目录权限问题，`chmod -R 777 volumes data logs` |
