# 察元 AI 桌面版（全量/集成版）安装使用教程

> 产物：`dist-full/Chayuan_2.0.357_aarch64.full.dmg`（macOS Apple Silicon，6.3GB）；
> Linux arm64 版（`.deb` / `.AppImage`）待 192.168.6.54 构建完成后放同一 `dist-full/` 目录。
> **全量版 = 内置全部本地模型**（chat Qwen3-4B / embedding bge-m3 / rerank / ASR / TTS），
> 装好即用，**全程无需联网**。

---

## 一、macOS 安装（Apple Silicon）

### 1. 安装

1. 双击 `Chayuan_2.0.357_aarch64.full.dmg` 挂载；
2. 把 **Chayuan.app** 拖入 `Applications`（应用程序）文件夹；
3. **首次打开**（应用未做商业签名，macOS 会拦）：
   - 方法 A：在「应用程序」里**右键 → 打开 → 再点"打开"**（只需一次）；
   - 方法 B：系统设置 → 隐私与安全性 → 底部「仍要打开」；
   - 方法 C（终端）：`xattr -cr /Applications/Chayuan.app` 后正常双击打开。

### 2. 首次启动（约 1~3 分钟）

1. 弹出「**欢迎使用察元 AI**」→ 选择**数据目录**（所有知识库、上传文件、配置都存这里，
   默认 `~/Library/Application Support/chayuan`，可改到空间大的盘）；
2. 显示「正在启动后端服务…」10~30 秒（建库 + 铺内置模型，属正常等待）；
3. 进入主界面即安装完成。

### 3. 打开界面 / 使用

- **主界面就是 App 窗口**：启动台/应用程序里双击「察元 AI」即开即用；
- 单机版默认**匿名模式**（GUEST），无需登录；若首屏弹「**设置管理员**」向导，
  设一个管理员账号密码即可（用于管理功能，日常使用仍免登录）；
- 全量版本地模型开箱可用：直接发起**对话**、建**知识库**上传文档问答；
  首次对话前本地模型需加载约 30~60 秒（界面有就绪状态提示）；
- 后端固定监听 `127.0.0.1:62581`（WPS 插件等集成连这个地址，不要改）。

## 二、Linux（arm64）安装

产物二选一（构建完成后在 `dist-full/`）：

```bash
# 方式 A:deb 包(推荐 Ubuntu/Debian)
sudo apt install ./Chayuan_2.0.357_arm64.full.deb   # 自动装依赖并注册应用
# 应用菜单找「察元 AI」,或命令行: chayuan-desktop

# 方式 B:AppImage(免安装,任何发行版)
chmod +x Chayuan_2.0.357_arm64.full.AppImage
./Chayuan_2.0.357_arm64.full.AppImage
```

首启流程与 macOS 完全一致（选数据目录 → 启动后端 → 主界面；默认数据目录 `~/.local/share/chayuan`）。
AppImage 若报缺库：`sudo apt install libwebkit2gtk-4.1-4 libgtk-3-0 libayatana-appindicator3-1`。

## 三、配置

| 项 | 位置 / 方法 |
|---|---|
| 数据目录 | 首启向导选择；**备份这一处即备份全部数据**（知识库/文件/配置/模型种子） |
| 管理员/登录 | 首屏向导设置；后续在应用内「用户管理」增删用户、切换登录模式 |
| 本地模型 | 全量版已内置；**换模型**：把新 GGUF 放入 `<数据目录>/models/bundled/<能力目录>/`（chat / embedding / rerank / asr），在应用内模型管理点「扫描挂载」或重启 App 自动注册 |
| 云端模型（可选） | 应用内「模型配置」填 OpenAI / 通义 / 智谱 / 火山豆包 等 API Key，即可用云端大模型（需联网；纯内网忽略此项） |
| 端口 | API 固定 `127.0.0.1:62581`，WPS 加载项/第三方集成填这个地址 |
| 日志排查 | `<数据目录>/logs/`；启动问题看最新 `start_main_server_*` 日志 |

## 四、常见问题

| 现象 | 处理 |
|---|---|
| macOS 提示「无法验证开发者」 | 见 §一.1 步骤 3（右键打开 / 仍要打开 / xattr） |
| 首次启动卡在"启动后端服务"较久 | 正常：建库 + 首次铺 6GB 模型；数据目录所在盘需 ≥10GB 空闲 |
| 聊天报「模型未就绪」 | 本地模型加载中，等 30~60 秒再试；或重启 App（会自动重挂） |
| 装不上/打开就退 | 确认架构匹配：mac 版仅 Apple Silicon（M 系列）；Linux 版仅 arm64（`uname -m` = aarch64） |
| 想多人通过浏览器访问 | 桌面版是单机形态；多人/网页形态用 Docker 离线包，见 `docs/离线部署教程.md` 与 `offline-install/` |

## 五、升级 / 卸载

- **升级**：下载新版安装包直接覆盖安装；数据都在数据目录里，不受影响；
- **卸载**：macOS 删 App + （可选）`rm -rf ~/Library/Application\ Support/chayuan`；Linux `sudo apt remove chayuan` 或删 AppImage + `~/.local/share/chayuan`。
