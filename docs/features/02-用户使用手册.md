# 察元 Chayuan · 用户使用手册

> 面向终端用户:每个功能讲清**在哪进入 · 怎么操作 · 注意事项**。
> 适用于桌面版 / 服务版(网络版)/ WPS 加载项;部分功能按版本与角色(管理员/普通用户/游客)可见性不同,文中会标注。

---

## 〇、开始之前

- **进入方式**:桌面版直接打开应用;服务版浏览器访问 `http://<服务器IP>:8080`;WPS 版在 WPS 任务窗格打开。
- **首次配置**:服务版首次打开若无管理员会弹「设置管理员」向导(设用户名+密码);桌面版本地直接用。
- **角色差异**:管理员可见「后台管理」;普通用户用常规功能;游客只读首页。**单机版所有功能放开**。
- **模型就绪**:若提示「未就绪:no local candidate」,说明没放本地模型——去「AI 平台能力中心」装模型,或配置云端模型(见 §6)。

## 一、智能对话

### 1.1 发起对话
- **进入**:顶部「新聊天」标签,或点左侧历史会话。
- **操作**:底部输入框(ChatComposer)打字 → 回车发送 → 回复流式逐字出现;可中途点「停止」。
- **注意**:草稿自动保存;消息自动落库,刷新不丢。

### 1.2 选模型 / 深度思考 / 高级参数
- **选模型**:输入框顶行的模型 pill → 按能力/厂商筛选 → 选定。
- **深度思考**:输入框顶行 ✨(Sparkles)按钮开关;复杂推理时打开。
- **高级参数**:聊天页顶栏「高级」→ 调 temperature/top-p 等;**注意**参数随当前对话保存。

### 1.3 工具 / MCP / 附件
- **工具/MCP**:输入框的工具图标 + MCP 图标 → 多选要启用的工具;执行结果以卡片显示在回复里。
- **附件**:输入框可上传文件、图片、录音、截图。**注意**录音依赖浏览器麦克风权限(单机 webview 可能不支持录音)。

### 1.4 多模型对抗(Arena)
- **进入**:聊天页「+ 添加」按钮增加泳道。
- **操作**:开「统一发送」一次发给所有泳道;可把某泳道拖成独立窗口对比。

### 1.5 产物面板(Artifact)
- **进入**:对话生成代码/文档/图片/视频时自动弹出,或聊天页切换按钮。
- **操作**:浮窗/全屏/内嵌切换;右上角下载;代码可预览编辑。

### 1.6 历史会话 / 还原 / 反馈
- **进入**:左菜单「历史」。
- **操作**:按时间分组浏览;右键重命名/删除;点开历史对话会**自动还原**当时的知识库/模型/参数。
- **反馈**:回复 hover → 点赞/点踩/标注(标注进入「训练数据中心」)。

## 二、知识库与检索

### 2.1 进入知识中心
- **进入**:左菜单「知识中心」(可展开:知识库 / 素材中心 / 视频中心)。
- **看到**:四类知识库卡片(文档 / 结构化 / 向量 / 图像)。

### 2.2 创建知识库
- **进入**:知识中心右上「+」。
- **操作**:选类型 → 填表单(文档库选 embedding 模型;结构化填数据库连接;向量库填外部地址;图像库选图像模型)→ 创建。
- **注意**:查询用的 embedding 模型**跟随知识库索引配置**,创建后查询端不能改。

### 2.3 上传与文件列表
- **进入**:点知识库卡片进详情页。
- **操作**:上传文件;文件以**卡片**展示,向下滚动**无限加载**;支持关键词搜索。
- **注意**:大库分页加载,首次进入只显示一部分,滚动出更多。

### 2.4 知识库检索 / 引用
- **进入**:知识库详情页底部 composer 提问。
- **操作**:选检索档位(精准 / 全面 / 速度)→ 提问 → 看带引用的结果;点引用 `[c1]` 查看原文片段。
- **注意**:来源类型不同显示不同——文档可下载原文,结构化显 SQL/表,向量显 collection。

### 2.5 文档全文总结
- **进入**:文件卡片上的「总结」按钮(前后台都有)。
- **操作**:点击 → 整篇 map-reduce 归纳;超大文档会先弹确认。
- **注意**:按内容哈希缓存,同文件再总结走缓存。

### 2.6 集合 / 文件夹同步
- **集合**:知识中心「集合」tab → 创建 → 把多个库归入 → 管理成员。
- **文件夹同步**:知识库管理里配置同步源(如外部文件夹)→ 跟踪 job 状态,增量更新。

## 三、结构化数据问答

- **进入**:选中一个「结构化」知识库(StructuredKbDetail)。
- **操作**:用自然语言问("有几个用户""上月销售额")→ 系统自动 schema linking + 生成 SQL + 只读校验 + 执行 → 返回**表格 + SQL 语句 + 诊断**。
- **注意**:所有 SQL 只读;表/列来自白名单;聚合问题走确定性模板,结果可核对。

---

## 四、多模态生成

### 4.1 文生图 / 图生图
- **进入**:对话框,使用一个支持「文生图」能力的模型。
- **操作**:直接输入画面描述 → 出图(在 Artifact 面板)。图生图:消息里上传图片 + 新描述。
- **注意**:LLM 会改写你的 prompt,界面显示「原话 / 改写」,可选择是否用改写版。

### 4.2 AI 视频生成
- **进入**:对话中用支持「文生视频/图生视频」的模型;或主页「AI 视频生成」对话化入口 / 高级模式。
- **操作**:输入文案(或上传图片+描述)→ 生成 → 视频出现在 Artifact / 视频中心。
- **注意**:视频生成耗时较长;高级模式可调分辨率/帧率/时长。

### 4.3 数字人 / 语音
- **数字人**:选择或上传形象 → 输入口播文案 → 生成;支持多形象、同框/分段。
- **语音合成**:对话 TTS 模式或设置里配 TTS 引擎,选音色;**克隆音色**:设置→AI 平台→TTS,上传参考音频。
- **注意**:克隆音色质量受参考音频清洁度影响(降噪/时长/CPU 上限),参考音频要干净。

### 4.4 图文成片
- **操作**:对话上传图片 + 文案 → AI 自动配音/特效/成片。

## 五、视频编辑器(桌面版 VG)

- **进入**:视频中心 / VG 编辑页(桌面版)。
- **操作**:时间轴拖拽素材;选中片段→右侧面板调几何/透明度/画中画;字幕轨编辑;插入文字/图形/贴纸/马赛克;项目设置改背景色/片头片尾;音轨混音。
- **注意**:**改完素材要重建 desktop 前端 + 重启 sidecar 才看到效果**(用户常测到旧版);片头/片尾、部分模板为付费功能,非会员合成自动拼片尾。

## 六、模型与推理管理

### 6.1 模型广场
- **进入**:左菜单「模型广场」。
- **操作**:按来源(全部/推荐/国内/国外/本地/聚合)和能力(对话/嵌入/重排/文生图…)筛选;表格分页浏览;「+」添加云端厂商(填 API 密钥/地址,实时验连通)。

### 6.2 AI 平台能力中心 / 本地模型
- **进入**:设置 → AI 平台。
- **操作**:左侧选能力(对话/嵌入/重排/TTS/ASR/OCR…)→ 右侧看「已装/推荐/自定义」→ 点推荐模型「安装」(显示下载进度)→ 设默认。
- **运行时**:「运行时」页启停本地模型服务(llama-server 等);**日志仅管理员可见**。
- **注意**:网络版的本地模型放在宿主机 `vendor/bundled_models`,放好 GGUF 重启容器自动扫描;embedding 必须是 GGUF 格式。

## 七、智能体与应用平台

### 7.1 智能空间(造应用)
- **进入**:左菜单「智能空间」。
- **操作**:创建应用 → 在应用编辑器配 Prompt/流程/授权 → 发布/共享;「运行时」看运行状态和日志。

### 7.2 应用市场
- **进入**:左菜单「应用市场」或首页卡片。
- **操作**:浏览/预览/fork/评分团队和公开应用。

### 7.3 MCP 服务 / 工具中心
- **MCP**:左菜单「MCP 服务」→ 添加/配置/测试 MCP server。
- **工具**:左菜单「工具中心」→ 管理 HTTP/Python/SQL 自定义工具。**注意**管理员可控每个用户能用哪些工具(工具页卡片上的个人开关)。

### 7.4 我的待办(人工节点)
- **进入**:左菜单「待办」或铃铛通知。
- **操作**:4 个 tab(待我处理/我发起/组待认领/已完成)→ 点「去处理」→ 对话式填表,AI 自动从对话提字段。

## 八、办公集成

### 8.1 WPS 加载项
- **进入**:WPS 任务窗格(可左/右/顶/底停靠);⌘K 命令面板快速跳转。
- **对话+写回**:侧边栏对话 → AI 建议点「应用修改」→ 选替换/插入/追加/批注等方式写回文档。
- **知识库**:点「知识库」打开 KbSelectorDialog 选知识源(本机桌面版/远程连接);回复下方「知识来源·N 条」展开看引用,文档来源可点 📎 下载。
- **文档工具**(右键菜单):字词审核、表格操作、样式清理、图像统一、**文档脱密**(加密敏感段+密码复原)。
- **注意**:WPS 环境能力有限,部分浏览器 API 不可用;历史会话本地保存。

### 8.2 在线办公(至臻版)
- **进入**:左菜单「察元办公」。
- **操作**:文档列表 → 拖拽新建或点文档进 OnlyOffice 编辑器 → 编辑 + AI 辅助。

## 九、账号、权限与后台(管理员)

### 9.1 登录 / 账户
- **登录**:右上「登录」或 `/login`;登录后按角色分流(管理员→后台,其它→首页)。
- **账户菜单**:右上头像 → 设置/关于/登出。

### 9.2 后台管理(仅管理员)
- **进入**:管理员登录后进 `/admin`。
- **可观测性**:Traces(调用链路)、Scores(质量评分趋势)、Outbox(待上传事件,长期 >100 要查 Langfuse)、Prompts。
- **模型平台**:启停厂商/模型、编辑能力字段。
- **系统服务**:看容器健康/日志;**网络版只能查看,重启受控**(单机版可真重启)。
- **用户管理**:开通/管理账号、席位授权(超额禁建)。

### 9.3 序列号 / 额度
- **进入**:设置 → 许可证。
- **操作**:输入序列号兑换额度/解锁功能;**注意**「已用」按本机记录去重,换机需重新激活。

## 十、下载与预览

- **预览**:点知识库文件 / 引用 / 产物 → 在预览面板在线查看(支持 DOCX/PDF/XLSX/PPT/视频/音频/图片/Markdown 等 9 类)。
- **下载**:预览面板下载按钮,或 Artifact 右上下载;统一走 `/v1/files` 端点。
- **注意**:网络版下载/预览走同源 stream;若点原文跳首页/要登录,多为部署的反代白名单问题(联系管理员)。

## 十一、常见问题速查

| 现象 | 处理 |
|---|---|
| 聊天/检索报「no local candidate」 | 没装本地模型 → AI 平台装模型,或配云端模型 |
| 改了功能没生效 | 多半是 sidecar/前端没重启或镜像没重建 |
| 录音按钮没反应 | 单机 webview 缺麦克风 API,用网络版或检查权限 |
| 模型下拉重复 | 重启 sidecar 即自愈 |
| 本地模型下载链接 | 国内用 ModelScope 可达,HF 不可达 |

> 按版本不同,部分功能(在线办公、智能空间、训练数据中心、BI)为至臻版专属;服务版/单机版的功能可见性也会随「单机 vs 网络」「管理员 vs 普通用户」调整。
