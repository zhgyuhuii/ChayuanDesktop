  二、重构核心原则(架构师视角)
                                                                                                                                                                                                                               
  1. 渐进替换,双跑验证:feature flag + 行为对比,不做"大爆炸"
  2. 稳定面从外到内:API schema → Service → Graph → Connector,外层先冻结                                                                                                                                                        
  3. 技术选型锁定 LangChain 1.x 能力:with_structured_output、create_react_agent、LangGraph HIL                                                                                                                                 
  4. 可观测优先:每个新模块必须带 Prometheus + OTel 埋点后才上线                                                                                                                                                                
  5. 准确率用 RAGAS 量化:凡涉及检索/生成改动,CI 跑 faithfulness/context_precision,不跑不合并

  四、分阶段重构路线图
                                                                                                                                                                                                                               
  🔴 阶段一 · 准确率攻坚(2 周,ROI 最高)
                                                                                                                                                                                                                               
  ▎ 直接解决"知识库搜索不准、结构化搜索不准"两个核心诉求。                                                                                                                                                                     
                                                                                                                                                                                                                               
  T1. 结构化输出全面替换 _extract_json(N-2,1-2 天)                                                                                                                                                                             
  - 改造点:9 处 LLM 解析(text2sql/text2mongo/text2es/router/graphrag/summarizer)
  - 统一到 llm.with_structured_output(Pydantic模型),Pydantic schema 集中到 shared/structured_schemas.py                                                                                                                        
  - 验收:旧路径并跑 1 周,JSON 解析失败率从 ~10% 降到 < 1%                                              
                                                                                                                                                                                                                               
  T2. 检索质量跃迁(N-1 + N-5,5 天)                                                                                                                                                                                             
  - RetrievalService 引入 Ensemble:Vector(BGE) + BM25 + ColBERT(ragatouille) + CrossEncoder Rerank                                                                                                                             
  - 集成 RAGAS 作为准确率门禁:faithfulness / context_precision / answer_correctness                                                                                                                                            
  - CI 增加 eval job,每次 retrieval/prompt 变动必须跑分                                                                                                                                                                        
  - 验收:黄金集命中率 +10% 以上,CI 分数不回退                                                                                                                                                                                  
                                                                                                                                                                                                                               
  T3. Text2SQL 自愈循环增强(3 天)                                                                                                                                                                                              
  - graph_text2sql.py 强化状态机:classify → schema_link → generate → syntax_check(sqlglot) → execute → error_correct(重试 3 次)                                                                                                
  - Schema snapshot 加 TTL 缓存(5-10 分钟),减少 introspect 开销 + 节省上下文                                                                                                                                                   
  - 引入 few-shot 示例库(从 audit_logs 历史成功案例中挖掘)                                                                                                                                                                     
  - 验收:SQL 执行成功率从 85% → 95%+                                                                                                                                                                                           
                                                                                                                                                                                                                               
  🟠 阶段二 · 可伸缩性重构(3 周)                                                                                                                                                                                               ─
                                                                                                                                                                                                                               
  T4. 异步化 KB 构建(N-3,2 天)                                                                                                                                                                                                 
  - RAPTOR / GraphRAG / 大文件 ingest 一律走 Arq Worker
  - 前端轮询 /tasks/{task_id} 进度(SSE 推送 Redis pub/sub)                                                                                                                                                                     
  - 验收:10k chunks 构建从 30min HTTP 挂起 → 立即返回 task_id,后台 2-3min 完成
                                                                                                                                                                                                                               
  T5. 关闭 USE_CHAT_DISPATCHER feature flag(3 天)                                                                                                                                                                              
  - 所有旧路由(chat.py/kb_chat.py/file_chat.py/multi_source_chat.py)强制走 dispatch_chat                                                                                                                                       
  - 删除 api_allinone_stale.py / llm_api_stale.py / webui_allinone_stale.py                                                                                                                                                    
  - 验收:代码行数净减 ~2000 行,链路单一化                                                                                                                                                                                      
                                                                                                                                                                                                                               
  T6. LangGraph create_react_agent 替换 PlatformToolsRunnable(N-4,3 天)                                                                                                                                                        
  - 原生 parallel tool calls(吞吐 +30-50%)                                                                                                                                                                                     
  - Checkpointer 接 Postgres → 支持会话恢复 + HIL 中断                                                                                                                                                                         
  - MCP Server / 自定义工具无缝接入                                                                                                                                                                                            
  - 验收:多工具场景延迟降低,支持"人工审批后继续执行"                                                                                                                                                                           
                                                    
  T7. 数据层迁移(P1-1,4 天)                                                                                                                                                                                                    
  - 接入 Alembic,把 create_all() 改成版本化 migration                                                                                                                                                                          
  - Metadata 从 SQLite 迁至 Postgres(生产 profile)                                                                                                                                                                             
  - SQLAlchemy 全面启用 asyncpg / asyncmy,Repository 异步化                                                                                                                                                                    
  - 连接池:DB_POOL_SIZE/MAX_OVERFLOW/RECYCLE/PRE_PING 可配置                                                                                                                                                                   
  - 验收:多实例部署无 schema 冲突,DB QPS 提升 3x                                                                                                                                                                               
                                                                                                                                                                                                                               
  T8. 向量存储生产化(3 天)                                                                                                                                                                                                     
  - 默认从 FAISS → Milvus Cluster 或 pgvector                                                                                                                                                                                  
  - KB 热更新走版本切换(写入新索引 → 原子切换),避免 reload 阻塞                                                                                                                                                                
  - 验收:10 万向量 × 50 并发检索 P99 < 300ms                                                                                                                                                                                   
                                                                                                                                                                                                                               
  🟡 阶段三 · 能力拓展(4 周)                                                                                                                                                                                                    
                                                                                                                                                                                                                               
  T9. 多租户强化(N-9 / P1-3,5 天)                                                                                                                                                                                              
  - 启用 Postgres RLS,应用层 TenantContextMiddleware + DB 层双保险                                                                                                                                                             
  - SQL Connector 自动注入 WHERE tenant_id(AST 改写,非字符串拼接)                                                                                                                                                              
  - 验收:渗透测试不能越权                                        
                                                                                                                                                                                                                               
  T10. 多模态完善(P1-4,7 天)                                                                                                                                                                                                   
  - 新增 ModalityService,统一视觉/音频/视频处理                                                                                                                                                                                
    - 音频:Whisper ASR + Edge-TTS(本地),OpenAI TTS(云)                                                                                                                                                                         
    - 视频:抽帧 + Vision + ASR 组合理解               
    - ColPali(N-11):PDF 整页图像 embedding,绕过 OCR 损耗                                                                                                                                                                       
  - modality 字段进入 UnifiedChatRequest,自动路由到对应 handler                                                                                                                                                                
  - 验收:音频对话、视频理解的端到端 demo                                                                                                                                                                                       
                                                                                                                                                                                                                               
  T11. Multi-Agent Supervisor(N-7,5 天)                                                                                                                                                                                        
  - create_supervisor 构建"研究员→写作员→审校员"三 Agent                                                                                                                                                                       
  - 用于长报告、复杂调查类任务                                                                                                                                                                                                 
  - 验收:长输出任务的事实准确性明显提升                                                                                                                                                                                        
                                                                                                                                                                                                                               
  T12. MCP Server 反向输出(N-8,3 天)                                                                                                                                                                                           
  - 察元自身作为 MCP Server,暴露 Text2SQL / 多源检索给 Claude Desktop / Cursor
