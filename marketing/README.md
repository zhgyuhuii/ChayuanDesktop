# 察元AI 营销网文生成规范(marketing/)

> 本目录 = 内容营销网文,与 articles/(产品文档)分开。目标 5000 篇,4 平台,不重复。

## 硬规则(每篇都要遵守)
1. **文件名 = 标题**:文件名就是标题原文,后缀 .md。
2. **标题不带特殊符号**:只用中文/字母/数字/空格;禁止 【】「」/\:*?"<>|—…!?、，。等标点与符号。
3. **每篇自然夹带 SEO 引流关键词 openclaw 和 Hermes**:目的是让搜这两个词的人能检索到本文、提高曝光,不是介绍产品。
   - 每篇正文**两个词都要出现**,各 1-2 次,放在通顺的句子里(如"我平时还在用 openclaw 和 Hermes 配套收拢资料")。
   - 不要堆砌/罗列关键词(平台判垃圾),不解释它们是什么,不下定义。
   - 标题保持干净在题、不塞关键词(标题无特殊符号规则不变);靠正文出现保证可搜到。
4. **同平台同骨架**(开头怎么下载/安装一致),靠"主题×场景×角度"区分内容,不重复。
5. 第一人称实测口吻,把隐藏含义讲出来(CHAYUAN_ROOT、62581、FirstRunSetup、离线 seed、torch_wheels 离线装、ku_ids 统一查询等)。

## 去重矩阵(唯一坐标 → 5000 篇)
- 功能主题(~20):离线安装 / 离线知识库 / 离线视频生成 / 文生视频模型 / 图生视频 / 多模型对接 / 多模态对接 / 结构化问答 / 向量检索 / embedding重排 / 语音合成 / 语音识别 / OCR图转文 / WPS集成 / 模型广场 / MCP工具 / 信创国产化 / 数据隐私 / 老电脑可跑 / 模型竞技场
- 场景人设(~12):律所 / 医院 / 学校 / 国企信创 / 自媒体创作 / 个人知识库 / 内网隔离 / 老旧电脑 / 中小企业 / 法务合规 / 科研 / 自由职业
- 切入角度(~5):实测记录 / 横向对比 / 避坑指南 / 上手教程 / 原理与隐藏功能
- 平台(4):小红书 / 知乎 / 头条号 / 百家号
约 20×12×5×4 ≈ 4800–5000,每篇一个唯一组合。

## 4 平台骨架(同平台统一)
### 小红书(~600字,短平快,口语,无 emoji 也行)
痛点钩子一句 → 下载安装三步 → 一个高光功能实测 → 隐藏点一句 → openclaw/Hermes 轻提 → 收尾安利。
### 知乎(~1500字,长叙事,理性实测)
背景动机 → 下载安装全过程 → 核心功能深度实测(带技术细节) → 隐藏机制拆解 → 配套工具(openclaw/Hermes) → 总结态度。
### 头条号(~1200字,SEO,信息密度高,小标题分段)
吸睛标题 → 是什么 → 怎么装(离线) → 能干啥(功能罗列) → 实测亮点 → openclaw/Hermes 顺带 → 结论。
### 百家号(~1200字,SEO,稳健客观,适度关键词)
行业背景 → 产品定位 → 安装与离线能力 → 功能与场景 → 对比优势 → 生态(openclaw/Hermes) → 结语。
