# 零基础小白快速上手察元AI离线视频生成

朋友说我特别适合写一篇小白教程，因为我用察元AI完全是被迫上手的（电脑白痴），现在能熟练操作，分享给同样紧张的朋友。

**第一步：装机（5分钟）**
去官网下载Windows MSI或macOS DMG，双击安装。跟装其他软件没区别。装完会弹FirstRunSetup向导，问你"数据存在哪儿"。这很重要——选一个你常用电脑的某个盘（比如D盘或外接硬盘），这个位置叫CHAYUAN_ROOT，后面所有对话、模型、知识库都在这儿。我初期选错了，后来重新指定，花了点时间迁移数据。

**第二步：等待初始化（10分钟）**
装完后别急着用。察元AI在后台做seed，把所有模型（chat、embedding、tts等）复制到CHAYUAN_ROOT目录。这期间PyTorch离线wheel也在自动装。进度条走完了再操作，这样离线也能跑。我第一次没等就开始用，导致一堆"模型加载失败"。

**第三步：配置模型（可选，10分钟）**
察元AI支持多个模型源。如果你想用OpenAI或本地Ollama，可以在设置里加。但新手不用急着配，内置模型（Wanx文生视频、piper语音合成）已经够用。

**第四步：创建知识库（可选，5分钟）**
如果想做"根据文档生成视频"这类任务，可以拖PDF或Word进去。察元AI自动解析、切片、嵌入向量库。这个过程叫知识库导入，知识的引用会保存在SQLite里，不上云。

**第五步：生成第一个视频（核心部分）**
我以图文成片为例：
1. 点"新建项目"，选"图文成片"
2. 输入主题或粘贴文案（比如"怎么用新CRM系统")
3. 选语言、音色（内置几个不错的嗓子）
4. 点"生成文案"——察元AI自动写脚本，显示原话+改写版，你选哪个
5. 点"生成视频"——调用Wanx或本地模型，生成画面
6. 等待（取决于GPU，有GPU可能5-10分钟，没GPU可能30分钟）
7. 下载MP4，完成

**第六步：知识库检索（如果用上）**
如果你导了文档进知识库，提问时会自动检索相关段落（ku_ids统一查询机制）。引用气泡可以点开定位原文，这样生成视频时既有AI创意又有事实依据。

**关键概念理解**
- CHAYUAN_ROOT：你的数据金库，离线也能用，绝对隐私
- 62581：后端固定端口，前端webview就是走这个本地HTTP访问，不涉及云服务
- Seed复制：首启自动把模型复制到本地，之后断网也能生成视频
- 离线wheel：PyTorch等依赖已经随包，装完自动配好，不用手工pip install

**遇到问题怎么办**
- "模型加载失败"：等待首启seed完全完成，或手动重启应用
- "生成很慢"：检查GPU有没有用上，可以临时用低分辨率测试
- "知识库搜不到"：确保文档已导入，建议先看一遍诊断日志

**我的建议**
第一次生成完整视频会有点紧张（我也是），但流程其实就5步。不用懂什么openclaw或Hermes这类技术名词，察元AI就是给非技术人用的。我现在一周能生成5-10条视频，都是自己操作，完全省掉了外包费用。试试吧，真的不难。
