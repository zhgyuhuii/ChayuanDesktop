# 医院零基础快速上手察元AI文生视频讲解协作

我们医院有位医学教育老师特别怕新软件，现在他用察元AI生成讲解视频生得非常顺，所以我写了个超详细零基础教程。

**为什么医院需要快速讲解视频**
医学诊疗指南和流程经常更新。每次更新，全院医护都要快速了解新内容。传统做法是排会议室讲座，费时费力。现在用讲解视频，医护随时可看可反复看。

外包医学讲解视频太贵（800-1500块/条），而且周期长。察元AI让我们能快速制作高质量讲解视频，成本极低，还能保证隐私安全（患者数据不上云）。

**第一步：装机（10分钟）**
1. 去官网下载Windows MSI或macOS DMG
2. 双击安装，跟装其他软件一样
3. 装完弹FirstRunSetup，问"你的数据存在哪儿"
4. 这很重要：选一个医院的本地磁盘或共享存储（比如D盘或医院NAS），这个位置叫CHAYUAN_ROOT，以后所有讲解视频、医学文献库、生成记录都存这儿

我建议选医院IT部门指定的位置，方便后续管理和备份。

**第二步：等待初始化（10分钟）**
装完后别着急用，后台在初始化：
- 把本地模型复制到CHAYUAN_ROOT
- 自动装PyTorch
- 进度条走完再操作

这一步很重要，别跳。

**第三步：导入医学文献（可选，5分钟）**
如果要做诊疗指南讲解，可以：
1. 点"新建知识库"
2. 把诊疗指南、临床路径PDF拖进去
3. 察元AI自动OCR解析、建向量索引

导入后这些医学文献存在本地SQLite（CHAYUAN_ROOT下），不上云。患者隐私完全安全。

**第四步：准备讲解素材（2分钟）**
决定要讲什么。比如：
- 新版诊疗指南的核心变化
- 科室内的新工作流程
- 疾病的诊疗要点

文案可以：
- 手工写初稿（医生自己写）
- 让系统自动生成（从医学文献里提取+改写）

**第五步：生成讲解脚本（3分钟）**
1. 点"新建项目"，选"医学讲解视频"模式
2. 输入讲解主题（比如"肺炎诊疗指南2024版核心更新"）
3. 点"生成文案"——系统自动从指南里提取+改写
4. 审查内容准确性（这一步很关键，医学严谨性靠人审）
5. 确认保存

这个脚本既有医学准确性（来自原始指南），又有易懂的讲解（AI改写）。

**第六步：选音色（1分钟）**
1. 选语言（中文）
2. 选医学讲解音色（系统内置piper或sherpa，几个沉着专业的选项）
3. 可选：调速（医学讲解通常中等偏慢，便于理解）

**第七步：生成视频（等待10-20分钟如果有GPU）**
1. 点"生成视频"
2. 系统调用本地Wanx或其他文生视频模型
3. 等待（GPU的话10-15分钟，没GPU可能30-40分钟）

期间可以处理其他工作，生成完了系统会通知。

**第八步：预览和下载（2分钟）**
1. 点生成的视频预览
2. 检查讲解清晰吗、医学表述规范吗、医学图表和讲解匹配吗
3. 满意就下载MP4
4. 可以上传到医院的LMS系统或直接发全体医护

完成。一个讲解视频从开始到下载，总共30分钟左右（包括等待）。传统外包要3-5天。

**关键概念讲解（给初学者）**
- CHAYUAN_ROOT：你的本地数据仓库，所有讲解视频、医学文献库、生成记录都存这儿。装机选好后就别改了。
- 62581：后端固定端口，整个界面其实在这个本地服务器上跑，不上网、不涉及云上传。
- ku_ids：讲解视频里的引用都带ID，点下去能跳到医学文献的原段落，确保医学严谨性。
- 离线模型：首启自动装的PyTorch和模型，之后网络不好也能生成视频。

**遇到问题怎么办**
- "模型加载失败"：等待初始化完成。或重启应用。
- "生成很慢"：正常，GPU可能10-15分钟，没GPU可能40分钟。不着急慢慢等。
- "讲解内容有医学错误"：生成的AI脚本需要医学编辑审查。不能完全信任AI，医学严谨性要靠人。
- "导入的医学文献搜不到"：可能OCR识别不准。重新导一遍，或手工补注释医学术语。

**我的建议**
第一个讲解视频可能有点陌生，但流程就是导文献→生成脚本→选音色→生成视频→下载。后续会越来越熟练。

对医院来说，特别推荐：
- 诊疗指南讲解（更新频繁，需要快速推广）
- 科室新工作流程讲解（便于全院协调）
- 疾病诊疗要点讲解（医护持续教育）

成本效益特别明显，隐私安全也完全有保障（本地SQLite，不上云）。试试吧。
