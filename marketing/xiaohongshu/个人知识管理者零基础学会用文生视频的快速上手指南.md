# 个人知识管理者零基础学会用文生视频的快速上手指南

给知识管理者量身定制的察元AI文生视频上手流程。

第一步：安装和选择知识库位置
装好察元以后，第一件事不是生成视频，而是理清楚三个目录的关系：
- CHAYUAN_ROOT：察元的数据根目录（模型、对话、生成的视频）
- 你的笔记库：比如Obsidian或Notion的本地目录
- 导出目录：最后的成片位置

建议三个分开，不要混合。这样迁移设备、备份、版本管理都更清楚。

第二步：生成你的第一条知识视频
找一篇你比较满意的笔记或文章，打开对话框，把核心内容一句话描述，比如"我学习了关于哈里森·伯吉斯的海岸线分形理论，用5分钟视频讲解这个概念"。点AI视频生成，选Wanx模型。

等待3到5分钟，视频就好了。用系统文件管理器打开CHAYUAN_ROOT目录，你会看到新生成的视频文件。

第三步：审看和决策
放到媒体播放器里看一遍，评估质量。看看是不是你要的感觉。如果不满意，在对话框继续改进prompt，重新生成。比如"这个太快了，能放慢速度吗""能加更多的视觉图表吗"。

第四步：编辑和融合
如果只是简单的知识讲解，可以直接用。如果想加你自己的补充、或者加引用链接，打开时间轴编辑功能，添加字幕、旁白、或者链接到原始笔记。

第五步：建立知识库的视频索引
为你的知识库单独建一个"视频资产"的目录结构。比如：
```
我的知识库/
  视频资产/
    心理学/
      神经可塑性.mp4
      认知偏差.mp4
    物理学/
      量子纠缠.mp4
      波粒二象性.mp4
```

每个生成的视频按学科分类存放。

第六步：建立链接和索引页
在Obsidian或Notion里建一个"视频导航"页面，用链接指向每个视频资产。这样看笔记时，如果想视频版的讲解，点一下链接就跳过去。

第七步：定期回顾和更新
知识是活的，你的笔记可能会更新。对于更新后的重要笔记，重新生成视频或更新原来的视频。保持知识库的多媒体内容和文字内容的同步。

第八步：建立个人知识分享库
把整个CHAYUAN_ROOT和笔记库打包给朋友或学习小组分享。他们也能离线使用你的整套知识系统，包括视频。这是云端知识平台无法做到的。

核心要点是把文生视频当成知识表现的"第二种格式"，而不是替代。文字笔记还是真源，视频是辅助和加深理解的手段。两者结合，知识管理的效率和效果都会显著提升。
