# 零基础科研党快速上手察元AI论文讲解视频生成

我本科时对任何新软件都紧张，现在用察元AI做论文讲解视频做得贼顺，所以特意写了个零基础教程。

**为什么要生成论文讲解视频**
导师要求整理课题相关的论文，做成中文讲解视频放在组wiki。用传统方法（逐句翻译+找素材+剪辑）要2-3天/篇，太低效。察元AI可以快速从论文自动生成讲解脚本+视频，我可以专注验证内容准确性而不是体力劳动。

**第一步：装机和初始化（10分钟）**
1. 去官网下载Windows MSI或macOS DMG
2. 双击安装（跟装QQ一样简单）
3. 装完打开，弹FirstRunSetup向导，问"你的数据放在哪儿"
4. 这里很关键：选一个大分区（比如D盘），这个位置叫CHAYUAN_ROOT，以后所有论文、向量库、对话都在这儿

我初期没重视这一步，后来有点后悔。选好以后别再改了。

**第二步：等待初始化（再等5-10分钟）**
装完后后台在自动初始化，把所有模型（chat、embedding等）复制到CHAYUAN_ROOT。进度条会走，走完以后就能离线用。期间PyTorch也在装，这是后面生成视频时需要的。

千万别着急，等完全初始化再操作。

**第三步：导入论文（2分钟/篇）**
1. 点"新建知识库"
2. 把论文PDF拖进去，或者上传Word版本
3. 察元AI自动OCR解析、切片、建向量索引
4. 等待（通常几秒到几分钟，取决于论文长度）

导入完后，论文的所有内容都在本地SQLite里，可以离线检索。

**第四步：生成讲解文案（3分钟）**
1. 点"新建项目"，选"论文讲解"模式
2. 输入论文标题或主题关键词（比如"蛋白质折叠的机制"）
3. 系统自动从论文里检索相关段落（这叫ku_ids查询，带精确引用）
4. 点"生成文案"
5. 系统会显示：原始引用段落 + AI改写的讲解版本
6. 你可以选其中一个，或手工编辑

这一步是核心。检查一遍内容是否准确，确保没有"瞎编"。

**第五步：选音色和语言（1分钟）**
1. 选语言（中文）
2. 选音色（系统内置几个不错的TTS音色，piper或sherpa等）
3. 可选：调整说话速度

**第六步：生成视频（最长等待）**
1. 点"生成视频"
2. 系统调用本地Wanx或其他模型，生成画面
3. 等待（GPU的话可能10-20分钟，没GPU可能30分钟）

这期间可以做其他事。生成完了系统会通知你。

**第七步：预览和下载**
1. 点生成的视频，预览一遍
2. 检查内容和画面有没有明显错误
3. 满意就下载MP4，上传到你的wiki或YouTube

完成。一篇论文讲解视频从开始到下载，大概30分钟（包括等待）。传统方法同样质量的视频需要2-3小时。

**关键概念讲解（给初学者）**
- CHAYUAN_ROOT：你的数据仓库，所有论文、向量索引、对话记录都在这儿。一旦选好不要改。
- 62581：后端固定端口，界面其实是在这个本地服务器上跑的，不涉及云上传。
- Seed初始化：首启时自动把模型复制到本地，之后断网也能生成视频。
- ku_ids：知识库查询时的追踪ID，帮助追溯引用来自论文的哪一段。
- 离线wheel：PyTorch等依赖已随包，装完自动配好，不用pip install。

**如果遇到问题**
- "模型加载失败"：等待初始化完全完成。或重启应用。
- "论文导入后搜不到内容"：可能OCR识别不准。手工补注释关键词。
- "生成视频很慢"：正常，GPU可能15分钟，没GPU可能45分钟。着急的话先用低分辨率快速验证。
- "生成的文案有错误"：这是正常的，科学严谨性还是要靠人审。不用完全信任AI。

**我的建议**
第一个论文讲解视频可能会花点时间熟悉，但流程其实就是导论文→生成文案→选音色→生成视频→下载。后续再做会快很多。

对比openclaw自建方案，察元AI装机即用，不用配置。对比云端服务，察元AI离线隐私，长期成本低。特别适合PhD/硕士生反复生成讲解视频。试试吧，真的不难。
