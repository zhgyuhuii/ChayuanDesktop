# 信创内网零基础入门察元AI多模型对接详细步骤

上周公司IT让我给全部门培训察元的使用，整理了一份最小化入门指南，分享给其他信创单位的朋友。

前置条件：你的公司IT已经：
1. 部署了一个内部的LLM服务（兼容OpenAI或Hermes格式）或者允许你用某个国产云模型的内部镜像
2. 为部分人分配了对应的API秘钥

第一步：下载和安装。
去公司内网资料库或IT部门拿察元的安装包（Windows MSI / Linux deb / macOS DMG）。双击安装，基本是next、next、next就完成了。装在C盘或公司指定的位置都可以。

第二步：首启配置数据目录。
第一次打开察元时会弹一个"首次启动向导"。关键环节来了——它会问你"CHAYUAN_ROOT设置在哪里"。这是你的所有对话记录、知识库索引、embedding向量库的存储位置。
- 如果是个人使用：默认位置（通常C:\Users\你\AppData）就行。
- 如果是团队共享：让IT创建一个NAS或共享盘位置，这里填那个UNC路径（比如\\\\nas\\chayuan_team）。这样所有人的知识库和对话会在同一个地方，便于团队协作。

第三步：本地模型seed自动复制。
向导会自动下载和复制chat、embedding、asr这些本地模型权重到CHAYUAN_ROOT。根据你的网络环境（内网通常比较快），这个过程3到10分钟。期间不要关闭应用。

第四步：配置内部模型服务。
向导完成后，打开"设置" - "模型" - "添加模型"。选"自定义API"（或"OpenAI兼容"），填写：
- 模型名称：可以随意，比如"公司LLM"
- Base URL：IT部门告诉你的地址，比如http://10.0.0.5:8000
- API Key：你被分配的秘钥，复制粘贴
- 模型型号：IT部门告诉你服务里支持的模型名，比如"hermes-7b"

点"测试连接"，如果提示成功，就说明配好了。

第五步：测试一次对话。
新建对话，左上角点模型下拉，应该能看到你刚加的"公司LLM"。选它，输入一句"简要介绍公司的主营业务"，按发送。察元会通过本地的62581后端端口把你的请求转发到内部模型服务，几秒钟返回答案。

第六步：上传知识库开始用。
把你的文档（PDF、Word、Excel、Markdown都支持）拖进知识库区域。察元会自动用本地embedding模型给文档分段和向量化，存到CHAYUAN_ROOT的SQLite里。这些都是本地操作，不走任何外网，符合信创要求。

完成！现在你可以问"上个季度的销售报告里，华东区的增长率是多少"这种问题。察元会在知识库embedding索引里找相关段落，再用你选的内部LLM深度分析。

进阶小贴士：
- 如果有多个内部模型服务，可以都加进来。对话时无缝切换。
- openclaw和Hermes是你内部模型服务用的协议标准，察元兼容，不用你操心。
- 每个人都有自己的对话历史记录（存在CHAYUAN_ROOT里），但知识库是共享的。

碰到问题先问IT部门确认内部服务是否在线、IP是否对。大多数问题都在这个环节解决。
