# 国企零基础员工用察元生成宣传视频完整教程

国企员工看这篇,真的能上手,不用任何技术背景。

**前期准备(15分钟)**

1. 下载察元AI(官网,选Windows MSI或Mac DMG或Linux AppImage)
2. 双击安装,选"自定义路径"
3. CHAYUAN_ROOT选本地固态硬盘,比如 `E:\company-data\chayuan`(不选网络盘!)
4. 继续安装,完成后会弹FirstRunSetup
5. 自动下载TTS、embedding等模型,约15分钟,不用操作,先处理其他公务

**整理企业素材(20分钟)**

1. 打开察元,左菜单"知识库",点"新建"
2. 名字填"企业宣传库"(或部门名)
3. 上传素材:企业年报PDF、产品介绍、员工故事等都拖进去
4. 察元自动切片、embedding、建索引(全在本地,不上云)
5. 完成后显示"已索引XX个文档"

**生成宣传讲稿(5分钟)**

左菜单"对话",消息框输入:
"根据企业宣传库,写一份关于<诚信经营>的宣传讲稿。要求:企业发言人风格,2分钟长度,包含具体案例,适合全员观看。"

察元会自动搜你的知识库,生成带引用的讲稿。点引用气泡能看"这句话来自企业年报第几页"。

**配音(3分钟)**

右菜单"语音合成",把讲稿粘进去,选piper中文"企业发言人"(男声,权威感),点合成。

MP3自动保存到 `chayuan-data\output`。如果对音色不满意,可以试试其他piper音色再合一遍。

**生成配图视频(5分钟)**

回到对话,输入:
"用文生视频生成一段<诚信理念>的视觉表达。包含握手、书签、承诺等企业元素,配色企业蓝RGB(0,51,102)和金色RGB(255,204,0),适合宣传片。"

Wanx模型开始生成,进度条显示进展。3-5分钟后出来一段短视频,自动存output。

**多轨合成(10分钟)**

1. 左菜单"视频编辑"或"时间轴"
2. 视频轨1:拖入AI生成的视频(0:00-1:00)
3. 视频轨2:如果有企业拍摄的员工故事视频,拖进去(1:00-2:00)
4. 音频轨:拖入你合成的MP3配音
5. 字幕:自动识别音频,你手动改错别字和企业术语
6. 右上"导出视频",选1080p,确认

视频保存到output,约200-300MB。

**审批与分发(5分钟)**

1. 送宣传部审核(通常2-4小时)
2. 上传到企业内网视频平台或员工App
3. 群发通知全员观看

**关键要点**

- CHAYUAN_ROOT是企业宣传资源的根,别乱改位置
- 首启会慢,不用急
- 知识库上传后搜索可能需要调试,加关键词标签有帮助
- 讲稿里的企业术语要明确(不是"增长",而是"复合年增长率")
- TTS选"企业发言人"(男声)更合适
- 多轨编辑超过20个clip时分批处理,避免卡顿
- 导出1080p H.264,兼容企业旧播放器

**真实时间投入**

从讲稿到导出,一个2分钟的企业宣传视频约1-1.5小时(含调整)。

相比外包(每个视频5000-10000块+2-3周周期),节省大量费用和时间。
