# 医院零基础用察元生成培训视频完整教程

医院新人看这篇,真的能上手。

**前期准备(15分钟)**

1. 下载察元AI(官网,选Windows版本)
2. 双击MSI安装,跳过快速安装,选"自定义"
3. 路径改成 `E:\Hospital\chayuan-data`(CHAYUAN_ROOT,务必选本地固态硬盘,不选网盘!)
4. 继续安装,完成后会弹"FirstRunSetup"对话框
5. 它会自动下载TTS、embedding等模型,大概15分钟,不用操作,先去干其他事

**组织医学内容(20分钟)**

1. 打开察元,左菜单"知识库",新建一个(比如"感染防控指南")
2. 上传院内的感控SOP文件(PDF或Word都行)
3. 察元自动切片、embedding、入库(这个过程叫RAG)
4. 上传完后,左菜单"对话",开始和AI聊天

**生成脚本(10分钟)**

消息框输入:"根据感染防控知识库,为护士编写一份3分钟的<洗手规范>培训脚本。要求逐步骤说明,每步配医学术语。"

AI会自动搜你上传的知识库(后台在62581调用kb-query/search),给出带引用的脚本。你可以点引用气泡看原文出处。

**配音(5分钟)**

右菜单选"语音合成",把脚本粘进去,选piper中文女护士音色,点合成。MP3存在CHAYUAN_ROOT的output目录,自动下载。

**生成配图视频(5分钟)**

再建一条对话,输入:"用文生视频生成一段<规范洗手>的演示视频,包含肥皂涂抹、流水冲洗、纸巾擦干的画面。"

系统用Wanx模型(或本地gguf)生成,3-5分钟出来。自动存output。

**合成最终视频(10分钟)**

1. 左菜单"视频编辑"或"时间轴"(版本可能略有不同)
2. 把生成的视频拖进去(第一轨)
3. 把你合成的音频拖进去(音频轨)
4. 如果有院内拍摄的洗手演示视频,也可以拖进去(第二视频轨)
5. 用素材库的"感染防控"海报或标题卡补充开头结尾
6. 对齐时间点,检查字幕对不对(自动生成的,可编辑)
7. 右上"导出视频",选1080p,点OK

**导出与分发(3分钟)**

视频会保存到output目录(CHAYUAN_ROOT下),可以直接拷贝到其他电脑或上传到院内医学教育系统。

**关键细节**

- CHAYUAN_ROOT是你的所有数据根,别乱动,备份时整体拷贝
- 后端在62581,对话能发消息说明后端在跑,才能生成视频
- 每个操作都有"进度提示"或loading,不要频繁点,耐心等
- 医疗内容生成后要科室审核,AI可能有小错误
- 多个人共用一台电脑,最好分Windows账户,隔离各自的项目

**常用快捷**

- 想加字幕:上传个带字幕的样本视频到知识库,问AI"参考这个字幕风格"
- 想换音色:语音合成页面有多个piper音色库,逐个试听
- 想加医学背景:知识库里上传医学图片或视频素材,多轨时拖进去
- 想批量做:把不同的医学内容分别建project,都操作一遍,后期统一管理

**真实时间投入**

一个3分钟的标准培训视频,从脚本到导出,实际操作时间约30分钟(不含审核和修改)。相比OpenClaw和Hermes,少了至少2小时的环境配置和参数调试。
