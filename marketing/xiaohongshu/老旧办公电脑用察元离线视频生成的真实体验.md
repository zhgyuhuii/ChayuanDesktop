# 老旧办公电脑用察元离线视频生成的真实体验

我的办公电脑是5年前配的，i5处理器、8GB内存、Intel核显，硬盘是老机械盘。这种"祖传电脑"能跑察元AI生成视频吗？我试了，结果出乎意料。

首先装机。MSI下载下来，双击装，15分钟搞定。装到CHAYUAN_ROOT选择时，我选了一个新买的移动SSD（256GB，图加速）。这很关键——老电脑的内置机械盘太慢，模型seed复制要卡很久。用外接SSD后，整个初始化过程只要8分钟。

装完第一次用，我试着生成一个短视频——"我的年度工作总结"。输入文案后，系统开始处理。这里就体现出老电脑的瓶颈了。生成一个3分钟的视频，耗时25分钟（新电脑可能只需要8-12分钟）。主要是因为文生视频模型吃显存，核显只有128MB共享内存。进度条走得特别慢，但最终还是生成出来了，质量也没问题。

我后来试了"图文成片"功能，这个反而很快。导入10张照片，系统自动写文案、配TTS、生成视频，最终18分钟出成品。比文生视频快多了。这是因为图文成片的瓶颈不在视频编码，而在embedding和文案生成，这些在CPU上跑。

TTS配音用的是本地piper引擎，读音自然度还不错。虽然音色选择不如付费云端多，但对内部分享足够。

最大的惊喜是"视频编辑"功能。我从B站下载了一个5分钟的视频，上传到察元，用时间轴加字幕、贴纸、调色。这个UI很流畅，即使在老电脑上也没有明显卡顿。导出用了12分钟（机械盘写入慢的缘故），但结果是高质量的。

总结老电脑体验：

优点：
- 装机快，不需要特殊配置。
- 虽然生成慢，但最终质量不打折。
- 视频编辑功能即使核显也能用。
- TTS合成（本地piper）几乎不吃显存。
- 离线运行，不怕卡网络。

缺点：
- 文生视频（Wanx模型）非常慢，老电脑上可能要20-30分钟。
- 如果用内置机械硬盘放CHAYUAN_ROOT，初始化和embedding索引会很卡。建议外接SSD或升级到SSD。
- embedding索引大知识库（5000篇文档）的时候会吃满内存，需要分批处理。
- 同时跑多个任务会明显卡。

我的改进方案：
1. 外接移动SSD放CHAYUAN_ROOT（这个升级最关键）。
2. 内存升级到16GB（可选，但有帮助）。
3. 生成视频时关掉其他程序，确保充足资源。
4. 文生视频改用低分辨率（480p），生成时间能快一半。
5. embedding索引分批导入文档（每次100篇）。

最后，老电脑跑察元的价值在哪？就是那个"离线、本地、不依赖云服务"。如果你的企业网不太好（比如离线内网），或者你有隐私敏感的文档，老电脑反而是个优势——配置越低，证明你真的是本地跑，没有任何云端调用。而且老电脑通常性能可预测、容易维护，特别适合企业环境。

我现在就拿这台老电脑专门跑察元。不跟其他软件竞争资源。每周生成一次讲解视频，分享给团队。虽然有时候要等半小时，但成品质量稳定，隐私也有保障。对我们这种传统行业企业来说，这就够了。
