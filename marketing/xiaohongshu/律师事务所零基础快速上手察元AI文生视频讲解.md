# 律师事务所零基础快速上手察元AI文生视频讲解

我们律所有个同事特别怕新软件，现在他用察元AI生成法律讲解视频生得特别顺，所以我写了个超详细的零基础教程。

**为什么律师需要视频讲解**
法律概念复杂，文字讲解客户理解难。视频讲解更直观，还能保留法律的严谨性（通过引用和追溯）。传统外包太贵（2000块/条），云端工具虽然便宜但隐私风险高（客户案卷要上传）。察元AI解决了"便宜、隐私安全、快速出视频"三个痛点。

**第一步：装机（10分钟）**
1. 去官网下载Windows MSI或macOS DMG
2. 双击安装，跟装其他软件一样
3. 装完弹FirstRunSetup，问"你的数据存在哪儿"
4. 这很重要：选一个本地磁盘（比如D盘），这个位置叫CHAYUAN_ROOT，以后所有讲解视频的素材、模型、参考法律都存这儿

我建议选一个备份频繁的分区，因为这是你的数据宝藏。

**第二步：等待初始化（10分钟）**
装完后别着急用，后台在自动初始化：
- 把本地模型（chat、embedding等）复制到CHAYUAN_ROOT
- 自动装PyTorch（后面生成视频需要）
- 进度条走完再操作

这一步不能跳，否则后面"模型加载失败"。

**第三步：导入法律法规或案卷知识（可选，5分钟）**
如果你要做某个法律条款的讲解视频，可以：
1. 点"新建知识库"
2. 把民法典、公司法、合同范本等PDF拖进去
3. 察元AI自动OCR解析、索引、建向量库

导入后这些法律文本都存在本地SQLite（CHAYUAN_ROOT下），不上云，隐私完全安全。

**第四步：准备讲解素材（2分钟）**
决定要讲什么。比如：
- 某个法律条款的解读
- 某类合同的风险提示
- 某个新法律的变化说明

文案来源可以是：
- 手工写的初稿（律师自己写）
- 从知识库里自动生成（系统从法律文本里提取相关段落）

**第五步：生成讲解脚本（3分钟）**
1. 点"新建项目"，选"法律讲解视频"模式
2. 输入讲解主题（比如"动产抵押的生效条件"）
3. 点"生成文案"——系统自动从法律文本里提取+改写讲解
4. 审查内容是否准确（这一步很重要，科学严谨性靠人审）
5. 确认后保存

这个脚本现在既有法律准确性（因为来自原始文本），又有通俗讲解（因为AI改写）。

**第六步：选音色和语言（1分钟）**
1. 选语言（中文）
2. 选音色（系统内置piper或sherpa等TTS音色，几个不错的选项）
3. 可选：调整说话速度（律师讲解通常中等偏慢比较稳重）

**第七步：生成视频（等待最长，10-20分钟如果有GPU）**
1. 点"生成视频"
2. 系统调用本地Wanx或其他文生视频模型
3. 等待（时间取决于你的GPU配置）

期间可以处理其他工作，生成完了系统会通知。

**第八步：预览和下载（2分钟）**
1. 点生成的视频，预览一遍
2. 检查音频清晰吗、画面和讲解内容匹配吗
3. 满意就下载MP4
4. 可以上传到律所的内部wiki或直接发客户

完成。一个讲解视频从开始到下载，总共30分钟左右（包括等待）。传统外包要2-3天。

**关键概念讲解（给初学者）**
- CHAYUAN_ROOT：你的本地数据仓库，所有讲解素材、法律文本、生成记录都存这儿。装机选好后别改。
- 62581：后端固定端口，界面其实在这个本地服务器上跑，不上网、不上云。
- ku_ids：知识库查询时的追踪ID。生成视频里的每条引用都带了ID，点下去能定位到法律文本的原段。
- 离线模型：首启自动装的PyTorch和模型，之后网络不好也能生成视频。

**遇到问题怎么办**
- "模型加载失败"：等待初始化完全完成。或重启应用。
- "生成很慢"：正常，GPU可能10-15分钟，没GPU可能40分钟。不着急的话慢慢等，着急就用低分辨率快速验证。
- "讲解内容有误"：生成的AI文案需要律师审查。不能完全信任AI，法律严谨性还是要靠人。
- "导入法律文本后搜不到"：可能OCR识别不准。重新导一遍，或手工补注释关键词。

**我的建议**
第一个讲解视频可能有点生疏，但流程就是导素材→生成脚本→选音色→生成视频→下载。后续会越来越快。

对律师事务所来说，特别推荐：
- 常见问题的讲解视频（一次投入，反复复用）
- 新法律发布的快速讲解（抢市场先机）
- 客户合同风险提示（保护双方）

成本和效率的提升非常显著。隐私安全也完全有保障（本地SQLite，不上云）。试试吧。
