# 老师零基础用察元生成教学视频完整教程

老师看这篇,真的能上手,不用任何技术背景。

**前期准备(10分钟)**

1. 下载察元AI安装包(官网,选Windows MSI或Mac DMG)
2. 双击运行,选"自定义安装"
3. 数据目录(CHAYUAN_ROOT)选本地硬盘,比如 `C:\Users\YourName\chayuan-data`(不选网络盘!)
4. 继续安装,完成后会弹"FirstRunSetup"对话框
5. 它自动下载TTS、embedding模型,约15分钟,不用操作,先去批改作业

**建立知识库(10分钟)**

1. 打开察元,左菜单"知识库",点"新建"
2. 名字填"高中化学-必修一"(或你的章节名)
3. 上传PDF:把教材章节或你的讲义PDF拖进去
4. 察元自动切片、embedding、建向量索引
5. 完成后会显示"已索引XX个文档"

**生成讲解脚本(5分钟)**

左菜单"对话",消息框输入:
"根据高中化学必修一知识库,写一份关于<氧化还原反应>的讲解脚本。要求:逐步骤说明,适合高一学生,5分钟长度。"

察元会自动搜你的知识库(后台在62581调用RAG),给出带引用的脚本。你可以点引用气泡看"这句话来自教材第几页"。

**配音(3分钟)**

右菜单"语音合成",把脚本粘进去,选piper中文"教师男声"(或选女声看你喜好),点"合成"。

MP3自动下载到 `chayuan-data\output` 里。如果有某个读音不对,可以重新调整参数再合一遍,或者手动录音替换。

**生成配图视频(5分钟)**

回到对话,输入:
"用文生视频生成一段<氧化还原反应>的动画演示。包含电子转移、原子价数变化、颜色变化三个阶段。适合教学演示。"

Wanx模型开始生成,进度条显示进展。3-5分钟后出来一段短视频,自动存output。

**多轨合成(10分钟)**

1. 左菜单"视频编辑"(或"时间轴")
2. 视频轨1:拖入AI生成的那个动画视频(0:00-2:00)
3. 如果你有自拍的实验演示(用手机录的),拖进视频轨2(2:00-5:00)
4. 音频轨:拖入你刚才合成的MP3
5. 自动生成字幕(asr自动识别),你过一遍改错别字和科学术语
6. 点"导出视频",选1080p,确认

视频会保存到output,约500MB。

**分享与使用(2分钟)**

1. 把video.mp4拷到学校的教学资源共享盘(或发给学生)
2. 可以在课前给学生预习,也可以在课后作复习资料
3. 下一次讲这个章节时,可以复用这个视频,省时间

**关键要点**

- CHAYUAN_ROOT是你所有教学资源的根,别乱改路径
- 首启会等,不用急,去喝咖啡
- 知识库上传后搜索可能需要调试(有时关键词差异导致找不到),可以加标签或改提问方式
- TTS音色要匹配讲解内容的严肃度
- 多轨编辑时,不要同时拖20+个clip,会卡;分批处理更稳
- 导出前在学校的投影仪/平板上测试一遍,确保格式兼容

**真实时间投入**

从脚本到导出,一个5分钟的教学视频约2小时(首次学习会慢,后续会快)。

相比OpenClaw和Hermes,你不用配置Python环境,不用自己装diffusers模型,一步到位。

试试看,教学视频没你想的那么复杂。
