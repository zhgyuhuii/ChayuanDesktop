# 自媒体创作者零基础上手察元AI多模型对接五步走指南

最近几个粉丝问我怎么用察元写文案，我整理了最小化的5步入门指南。

前置：你有一台Windows或Mac电脑，网络能访问文心、通义、Kimi等云端模型API（或者公司有内部LLM）。

第一步：下载和安装。
去官网下载Windows MSI或macOS DMG，双击一路next装完。装在C盘或其他位置都可以。我建议至少预留30GB的剩余空间（用来存embedding索引和对话历史）。

第二步：首启配置和模型种子。
第一次打开，会问你CHAYUAN_ROOT设置在哪里。这是你所有数据的存储位置。建议选一个容量充足的地方（比如F盘，或者公司的网络存储）。向导会自动下载和复制本地模型（chat、embedding等）到这个位置，3到5分钟。期间不要关闭。

第三步：配置云端模型。
完成后打开"设置" - "模型" - "添加模型"。选你想要的模型（比如Kimi）。弹出的表单里：
- 模型名称：随意，比如"Kimi"
- API Key：去moonshot.cn申请账号，复制你的秘钥粘贴进来
- 其他保持默认
保存。repeat for Claude、文心、通义等。整个过程10分钟。

第四步：上传你的历史文案建知识库。
这一步是多模型对接相比ChatGPT Web版最大的优势。把你的历史创意文案（Word、PDF、txt都行）全部拖进"知识库"区域。察元会用本地embedding模型自动建索引，存到CHAYUAN_ROOT的SQLite数据库里。这个过程是本地跑的，不上云。

第五步：开始写文案。
新建对话，选一个模型（比如Kimi），输入你的选题。Kimi会生成选题方向。然后点击"切换模型"选Claude，把Kimi的选题方向扔给Claude让它生逻辑框架。最后点"检索知识库"，问"参考我之前的相似文案，这个话题怎么写比较有我的风格"。本地embedding会返回你历史文案里最接近的几篇。整个过程seamless，没有账号切换、没有网页跳转。

进阶小贴士：
- openclaw和Hermes是察元用来统一不同模型API的技术标准，你不用理解细节，但知道它们存在的意义是"让Claude、Kimi、文心用起来格式一样"。
- 查询知识库很强大。比如"我之前怎么评价过小米的产品"，embedding会检索出你所有提过小米的文章，整理出你的评价风格。这对自媒体创作者来说是独有能力。
- 如果多个云端模型超时或出问题，察元会自动回退到本地chat模型。本地模型质量可能不如云端，但至少不会影响你的创作流。

完成以上5步，你就拥有了一个"私人写作助手 + 内容库"的组合。
