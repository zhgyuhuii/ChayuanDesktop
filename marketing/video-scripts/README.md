- 产品事实库（防编造，写脚本必读）：[`_facts.md`](_facts.md)
- 脚本模板：[`_TEMPLATE.md`](_TEMPLATE.md)

## 命名与对应约定（关键）

- 脚本文件：`NN-MM-<slug>.md`（NN=人群号，MM=01..10 群内序号，slug 为中文短描述）。
- 同名素材文件夹：`NN-MM-<slug>.assets/`，内含 `screenshots/ images/ video/` 三子目录。
- 脚本素材清单里每个文件名都写死，与 `.assets/<类型>/` 下应放文件**完全一致**。
- 二进制媒体（截图/配图/视频）由团队或察元自带的文生图/文生视频/数字人能力按文件名填入即对齐。

## 漏斗阶段说明

| 阶段 | 时长 | 目的 |
|---|---|---|
| 认知钩子 | 15s | 痛点切入，制造"这说的就是我" |
| 功能种草 | 30s | 单一核心功能演示，给"啊原来能这样" |
| 对比选型 | 45s | 与云端/竞品对比，给选择理由 |
| 转化行动 | 20s | 临门一脚，引导下载/装机 |
