## 产品定位
- 名称：**察元 AI · Chayuan AI 桌面单机版**（当前版本 2.0.162）。
- 一句话：装到电脑里就能用、**不联外网也能跑**的 AI 助手。
- 核心标签：离线优先 · 国产系统适配 · 全栈本地知识库 · 多模型对抗 · 免费开源（AGPL-3.0）。
- 数据主权：所有数据落到用户自选目录，**密钥与文档永不出域**。

## 一套引擎四档 SKU（可提，但桌面脚本主打"桌面单机版"）
- WPS 加载项（chayuan-wps）：写进 WPS/Office 文档。
- 桌面单机版（本脚本主角）：装进个人电脑，断网可跑。
- 网络版 Docker：服务版 / 至臻版，多人共用、浏览器即开。

## 技术形态（可在脚本"硬核拆解"类用）
- 后端 sidecar 本地端口：**62581**（不是 7861）。
- 数据目录环境变量：**CHAYUAN_ROOT**，用户可自选位置；知识库实际在 `<CHAYUAN_ROOT>/data/knowledge_base/`。
- 技术栈：Tauri 2 + React 19 桌面壳；Python 3.12 后端引擎。
- 开源协议：AGPL-3.0。

## 核心能力清单（只能引用这些）
1. **对话与流式**：多供应商大模型网关，统一接入。
2. **五类知识源**：① 文档知识库（PDF 等，引用气泡可回跳原文）② 结构化数据（数据库连接器，"有几个用户/订单总额"走 SQL 只读查询）③ 向量库 ④ 办公私有知识库 ⑤ 外部向量源。
3. **模型广场 / 全模型支持**：可挂本地与各家模型，支持 Ollama 等本地推理。
4. **本地推理**：老电脑可用 sqlite-vec 做本地索引；embedding / rerank 本地化。
5. **30+ 内置工具 + MCP 协议**。
6. **模型对抗（Arena）**：多模型同题对比。
7. **多模态**：语音合成（TTS，含本地引擎/克隆音色）、图转文、音转文。
8. **视频能力**：**文生视频 / 图生视频 / 数字人**；视频生成器（VG）带时间轴、字幕、画中画、背景/片头片尾、素材库。
9. **WPS 联动**：侧边栏 AI 对话、文档操作、知识库绑定、引用展示。
10. **国产化适配**：Windows / macOS / Linux / **麒麟 / 统信 UOS / openKylin**。
11. **安全隐私**：离线/内网物理隔离可用，数据不出域，适合涉密/信创/合规场景。
